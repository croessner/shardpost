# ShardPost 0.34.1: a namespace's root mailbox in an account import

Date: 2026-09-30

## Change

Dovecot lists the mailbox a public namespace is rooted in — `Zabbix` of
`namespace { type = public; prefix = Zabbix/ }` — when the personal
namespace is listed. `shardpostctl migrate` recognized the mailboxes of
another namespace by its prefix only, so it took `Zabbix` for a mailbox
of the account and copied the public folder into it.

Found on the first live run for `lists@srvint.net` (74 messages of its
own): the run was importing `Zabbix` (10701 messages) and `Postfix`
(1604) into the account and was stopped. The root mailbox now counts as
part of its namespace; the next run of the account prunes the two
mailboxes again.
